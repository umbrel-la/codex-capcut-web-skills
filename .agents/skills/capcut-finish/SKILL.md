# Чистовой монтаж в Codex

Прочитай [выбор задачи](../reel-director/references/task-routing.md). Принимай готовый MP4, EDL/черновик или существующий проект; референс необязателен, когда стиль задан словами или известен. Для продолжения используй STATE.md. При готовом монтаже сохраняй его длительность, порядок сцен, речь и звук, меняя только заказанные элементы. Разделы ниже применяй по необходимости; motion-only не включает автоматическое создание субтитров/музыки, caption-only — AI rough cut.

При отсутствии EDL считай готовое видео непрерывной основой с сохранением тайминга; для добавления графики полная повторная расшифровка и новый отбор фраз не нужны. Уже запечённые фон/текст не являются отдельными слоями: для их замены найди исходники либо подготовь и проверь маску/пересборку.

## Разбор оформления

Сохрани `analysis/reference_analysis.md`: композиция, шрифтовые признаки, количество слов, размеры/позиции текста, цвета, движение, ритм и звук. Отличай измеренное от предположенного. Анализируй последовательности кадров на появлениях/исчезновениях и склейках; точное имя шрифта не выдумывай.

Для нового вертикального рилса без иных параметров холст 1080×1920; при оформлении готового видео сохраняй его формат, проверив поддержку нужных параметров инструментом. Не растягивай горизонтальные шаблоны в вертикаль: заново расположи элементы. Сохраняй лицо и смысловые детали интерфейса, учитывай безопасные поля выбранной площадки на протяжении всей анимации.

## Слои и графика

- Базовые видео, субтитры, текст, музыка и доступные эффекты делай редактируемыми средствами CapCut через актуальные инструменты плагина.
- Привязывай действия скринкаста к словам: кнопка/ввод/результат; при необходимости скрывай личные данные. Сначала используй реальную запись пользователя, потом подходящие иллюстрации и схемы.
- При нужной программной анимации используй локальные SVG/HTML/Remotion/ffmpeg по доступности. Исходный код храни в `graphics/`; вывод — минимум 1080×1920 для полноэкранной вертикальной композиции. Слой с альфой проверяй на реальном фоне. Не называй отрендеренный клип редактируемыми объектами CapCut.
- Для графиков бери реальные данные. Русские надписи и числа накладывай точным текстом; не полагайся на их генерацию внутри видео. Не вставляй чужие QR-коды, CTA или логотипы из примеров.
- Используй нужные приёмы референса: крупность, маска, рамка, карточка, типографика, счётчик, стрелки; количество карточек/светлых сцен не ограничено произвольной нормой из старого комплекта.
- Генерации выполняй по [Higgsfield-памятке](../reel-director/references/higgsfield.md). Все финальные генерируемые видео минимум 1080p; проверяй реальные пиксели и качество, не только пункт в запросе.

## Субтитры и звук

Automatic-caption выполняй через установленный `CapCut:video-editing`: распознать, дождаться результата, применить, сохранить. Не переключай caption-only запрос на AI Lab из-за длинного ответа или сбоя. Используй точные session/batch IDs и процедуру тарифа из плагина.

Проверь распознанные слова по аудио, особенно имена, числа и бренды. Шрифт должен поддерживать кириллицу. Цвет подсветки, пунктуация, регистр и частота появления — по референсу и читабельности. Не считай фиксированное смещение −80 мс универсальной коррекцией ASR; измеряй на этом материале.

Сохрани исходный голос. Музыка поддерживает речь; SFX нужны для смысловых акцентов. Новую музыку выбирай из реально доступного каталога Higgsfield/CapCut в рамках бюджета. Ключ стороннего сервиса в среде сам по себе не разрешает расход.

## Сохранение и сдача

Учитывай текущую версию облачного проекта и изменения пользователя; применяй save/conflict workflow установленного плагина. Экспорт не считай доступным, пока не проверен способ получения реального файла. Разрешённый локальный рендер сохраняет EDL, текст/графику/звук и воспроизводимые параметры сборки.

Проверь запрошенный результат по параметрам этой задачи: длительность готового видео должна сохраниться при motion-only/субтитрах, формат и FPS — соответствовать заданию. Для вертикального H.264/AAC MP4 используй `../reel-director/scripts/reel.mjs verify` с явными --duration и --fps; для другого формата — ffprobe и проверку конкретных характеристик. Просмотри анимацию со звуком и сравни с заданием/референсом. Для отдельного графического материала проверь также альфу/цикл, если они нужны. Технический отчёт не заменяет визуальную приёмку.

Версии экспорта сохраняй отдельно. Сообщи ссылку на сохранённый проект и путь к MP4; если одно отсутствует, укажи конкретный блокер. Для паузы обнови `STATE.md`.
