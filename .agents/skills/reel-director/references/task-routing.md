# Выбор задачи перед монтажом

Сначала определи задачу по текущему сообщению и известному контексту. Пользователю достаточно обычного описания; названия навыков, заполнение шаблона и технические параметры не обязательны. Кратко назови выбранный режим и продолжай без подтверждения очевидного выбора.

## Какой этап выполнять

| Запрос | Маршрут | Что сохранять |
|---|---|---|
| «Сделай рилс из длинного видео», «выбери сильный фрагмент» | reel-director → capcut-rough-cut → capcut-finish в пределах заказанного результата | Смысл исходной речи; длительность и оформление по заданию |
| «Убери паузы/неудачные дубли», «собери черновик» | capcut-rough-cut; finish только для необходимых операций сборки | Естественность речи; без незапрошенных графики, музыки и новых генераций |
| «Добавь motion», «улучши фон», «оформи готовое видео» | capcut-finish | Длительность, порядок фрагментов, речь и звук, кроме явно заказанных изменений |
| «Только субтитры», «поправь одно слово», «сделай музыку тише» | Только соответствующая операция capcut-finish и протокол выбранной платформы | Все остальные элементы |
| «Продолжи», «поправь предыдущую версию» | Сначала указанный STATE.md и последние правки, затем нужный этап | Текущая работа, версии, одобренные решения и идентификаторы оплаченных задач |
| «Сделай только анимированную плашку/фон» | Подготовка конкретного материала по capcut-finish | Без сборки целого ролика, загрузки в CapCut или платной генерации, если это не нужно по запросу |

При сочетании задач выполняй только нужную комбинацию. «Добавь motion» к длинному видео тоже не означает разрешения сократить его. Разбор чужого промпта, ответ на вопрос или ревью не запускают монтаж.

## Параметры и входные материалы

- Приоритет: явный текущий запрос → согласованные параметры этой работы/STATE.md → подходящие значения по умолчанию. Уточняй только существенный конфликт или недостающий материал; не спрашивай то, что уже есть в чате/файлах.
- Только для нового вертикального рилса без заданной длины ориентир — 30 секунд, 1080×1920. Назови предположение перед работой. Для оформления готового видео измерь его длительность, соотношение сторон и FPS и сохраняй их. Изменение FPS ради совместимости требует проверки тайминга и звука; не ускоряй речь.
- Параметры проверки и число кадров вычисляй из выбранной задачи. Примеры с 30 секундами/900 кадрами не переопределяют готовый ролик на 44, 60 или 90 секунд.
- Референс нужен, когда пользователь просит воспроизвести конкретный пример. Если стиль описан словами или есть согласованное оформление, отдельный референс необязателен. Для субтитров/уровня звука/точечной правки не запрашивай его.
- Различай исходное видео, готовый монтаж, файл проекта и стилевой референс. Если дан только путь к папке с несколькими подходящими видео и выбор неочевиден, уточни конкретный файл.
- При запросе только оформления сохраняй существующие склейки. Распознавай речь лишь в объёме, необходимом для синхронизации/новых субтитров; не повторяй готовую расшифровку без причины.
- Субтитры, музыка, SFX и генерации — отдельные решения. Их наличие в примерах не делает их обязательными в каждом задании. Для Web caption-only используй automatic-caption workflow установленного плагина, без AI rough cut.
- Качество новых визуальных материалов — от 1080p в выбранном формате. Если исходник хуже, не обещай восстановленных деталей за счёт увеличения размеров.

## Проект и инструменты

- Режим Web/ПК определяется явным выбором пользователя, затем текущим STATE.md, затем AGENTS.md этого комплекта. Ошибка подключения не разрешает менять платформу. При явном переходе прочитай инструкции целевого комплекта и сохрани исходную работу.
- Новый ролик получает следующую свободную рабочую папку. Продолжение использует существующую; для переноса между Web и ПК создаётся отдельная копия с указанием происхождения.
- Полный ПРОМПТ_ДЛЯ_НОВОГО_ЧАТА.txt — необязательный шаблон нового рилса. Не загружай и не выполняй его автоматически для motion-only, субтитров или продолжения. Промпты с reel_v9 / Reel_PC_02 / конкретными путями относятся только к той работе.
- Общие программы init/verify в текущем комплекте рассчитаны прежде всего на вертикальный рилс. init требует отдельное видео-референс, verify проверяет 9:16. Не подставляй фиктивный референс и не перекраивай задачу ради утилиты. Для другой задачи подготовь рабочую папку и фактические метаданные по поддерживаемой схеме; проверяй заявленные параметры непосредственно через ffprobe и просмотр.
- Перед использованием настольного адаптера проверь поддерживаемые размеры, схему проекта и необходимые операции. Эти инструкции не добавляют поддержку нового формата к коду. При несовместимости продолжай разрешённую подготовку и объясни конкретное ограничение; изменение кода требует проверки, а защита от чужих правок сохраняется.
- Готовый MP4 не содержит исходных редактируемых слоёв. Дополнительную графику можно наложить поверх; замена запечённого фона/текста требует исходников, маски или пересборки композиции. Не клади новый фон под непрозрачное видео с обещанием видимого результата.
- Если запрошен только материал/MP4, создание проекта CapCut не становится обязательным. Если запрошен проект, отдельно проверь его сохранение/открытие; локальный MP4 этого не доказывает.

В STATE.md запиши выбранный тип задачи, платформу, что менять/сохранять, целевые параметры, фактически выполненные шаги и оставшееся действие. Разрешения на платные операции и правила сохранения выбранного комплекта остаются в силе.
