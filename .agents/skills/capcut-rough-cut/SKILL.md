# Черновой монтаж в Codex

Прочитай [выбор задачи](../reel-director/references/task-routing.md). Этот навык нужен для выбора и перестановки/удаления фрагментов; для одной графики или субтитров переходи к capcut-finish. При выборе рилса из длинного исходника анализируй весь материал и собирай законченную мысль. При просьбе только убрать паузы/дубли сохраняй содержание и порядок оставшегося материала, без автоматического сокращения до 30 секунд. Стилевой референс для чистки речи не обязателен.

## Анализ и отбор

1. Проверь ffprobe: длительность, отображаемую ориентацию, FPS/VFR, размер и звук. Исходник около 1 ГБ читай с диска. Для ASR/контакт-листов делай отдельные производные в папке работы, связывая их время с оригиналом.
2. Выбери доступное распознавание: CapCut automatic-caption по установленному навыку или уже доступный локальный ASR. Подписку/стоимость выясни до платного шага. Не требуй установки whisper.cpp, если задача решается имеющимися средствами.
3. Сохрани полную расшифровку и карту покрытия. Несколько кадров и фрагментарная ASR не равны анализу всей записи. Отдельно отметь нераспознанные участки и визуально важные моменты скринкаста.
4. Для нового рилса выбери связку начало → раскрытие → завершение. При чистке готовой речи сохрани её историю. Оставляй наиболее убедительный и чистый дубль; последний не обязательно лучший. Убирай только заказанные паузы/фальстарты/повторы, сохраняй естественность. Тишина не всегда означает ненужный кадр.
5. Не склеивай высказывания с изменением смысла, не обрезай тихие согласные и окончания. Проверяй вход/выход на слух и по соседним кадрам. Темп и целевую длину подбирай фрагментами, а не механическим ускорением всей речи.
6. Запиши `analysis/cut_list.md` и `analysis/edl.json`: каждый элемент содержит `source`, `source_in_s`, `source_out_s`, `timeline_in_s`, `timeline_out_s`, `speed`, `reason`. Значения конечны, диапазоны внутри файла; длительность таймлайна согласована со скоростью и FPS. Приводи границы к кадрам финального таймлайна, учитывая VFR источника.

## Сборка

- Основной путь — установленный `CapCut:video-editing` для нарезки/сборки и `CapCut:capcut-stdraft-builder` для точных правок. Загружай только необходимые ресурсы штатным uploader, сохраняй VID/URI. Не придумывай формат stdraft или поля API.
- Результат AI rough cut проверь по своему EDL и целевой длительности задачи. Не повторяй уже отправленную задачу, продолжай по её session/event IDs.
- Если запрос только на субтитры к неизменённому видео, используй automatic-caption workflow, не AI Lab.
- Голос выровняй при необходимости на отдельной копии; сохраняй оригинал. Уровни оценивай по всему миксу и разборчивости, не обещай гарантированный результат по одному числу LUFS.
- При недоступном CapCut сохраняй расшифровку/EDL и продолжай разрешённую локальную подготовку. Отдельно укажи, что облачная сборка ещё не выполнена.

Сдай черновик с выбранными исходными таймкодами, длительностью и замечаниями по речи/синхронности. Для полного рилса продолжай [чистовой монтаж](../capcut-finish/SKILL.md) без промежуточного согласования каждой склейки, если пользователь не просил этапную приёмку.

## Настольный CapCut — только отдельный режим

При явной просьбе перейти на ПК используй [отдельный комплект для ПК](https://github.com/umbrel-la/codex-capcut-desktop-skills), начав с его AGENTS.md. Существующий Web-монтаж сохраняй; перенос выполняй отдельной копией по запросу пользователя.
