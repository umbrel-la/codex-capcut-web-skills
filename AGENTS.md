# CapCut Web — рабочие инструкции для Codex

Для задач монтажа сначала прочитай .agents/skills/reel-director/references/task-routing.md. Выбери этап по запросу: новый рилс, черновой монтаж, оформление, субтитры, отдельный материал или продолжение. Не расширяй частичную задачу до полного монтажа. Пользователь может писать обычным языком; большой шаблон ПРОМПТ_ДЛЯ_НОВОГО_ЧАТА.txt необязателен.

По умолчанию новый вертикальный рилс без указанной длительности — около 30 секунд, 1080×1920. Для готового видео сохраняй существующие длительность, склейки, формат, речь и звук, если пользователь не попросил изменить их. При продолжении сначала прочитай указанный STATE.md.

Используй CapCut Web через установленный и авторизованный плагин, руководствуясь его актуальными навыками. Сохранение облачного проекта и получение MP4 проверяй отдельно. Наличие этой папки не устанавливает плагин. При caption-only используй автоматическое распознавание и применение субтитров по workflow плагина, без AI rough cut.

Новые работы помещай в следующую свободную _монтаж/reel_NN внутри репозитория; существующие продолжай в их папках. Не записывай секреты, токены, cookies и ссылки OAuth в файлы. Не загружай личные медиа в Git.

Higgsfield используй для полезных недостающих материалов при доступном подключении. Применяй бюджет текущей задачи, учитывай обязательные подтверждения и не повторяй оплаченные запросы. При явном поручении делегирования одному субагенту используй его, если доступно; иначе работай самостоятельно. Генерируемые визуальные материалы — от 1080p, если это возможно и требуется.

Готовый MP4 не предоставляет раздельные исходные слои. Для замены запечённого фона или текста могут потребоваться исходники, маски или пересборка. Проверяй ограничения реальных инструментов и не обещай неподдерживаемые функции.
