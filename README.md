# Codex + CapCut Web: навыки для монтажа видео

Набор инструкций и локальных утилит для работы в Codex с облачным CapCut. Можно сделать рилс из длинного исходника, оформить готовое видео или попросить одну конкретную правку. Навыки подбирают нужный этап по сообщению пользователя.

Для настольного CapCut на Windows есть [отдельный комплект для ПК](https://github.com/umbrel-la/codex-capcut-desktop-skills).

## Что умеет

- Анализировать исходник, отбирать фрагменты и собирать историю для нового рилса.
- Чистить речь от пауз и дублей в пределах задачи.
- Оформлять готовый монтаж: графика, фон, анимированные надписи, субтитры, музыка и звуковые акценты.
- Продолжать начатую работу по сохранённому состоянию `STATE.md`.
- По необходимости использовать Higgsfield для дополнительных материалов в рамках согласованного бюджета.

Запрос «добавь motion-графику» сохраняет длительность, склейки, речь и звук, если не заказано иное. Для нового вертикального рилса без указанной длины ориентир — 30 секунд, 1080×1920. Референс может быть файлом или описанием; для точечной правки он не обязателен.

## Что потребуется

1. Codex с возможностью читать локальные файлы и выполнять команды.
2. Установленный и авторизованный плагин CapCut для Codex с инструментами Web/MCP. Этот репозиторий сам плагин не устанавливает и вход не выполняет.
3. Node.js и FFmpeg с `ffprobe` в системном `PATH`. Для распознавания речи и генераций набор инструментов зависит от задачи и доступных подключений.
4. Для Higgsfield — его отдельное подключение; платные операции зависят от тарифа и бюджета.

Большой исходник можно указать локальным путём. Перед загрузкой в конкретный сервис проверяйте доступность его инструмента, ограничения и состояние задачи. Не помещайте видео, токены и служебные файлы проекта в публичный Git.

## Установка

```bash
git clone https://github.com/umbrel-la/codex-capcut-web-skills.git
```

Откройте скачанную папку как проект в Codex и создайте в ней чат. Codex читает инструкции `AGENTS.md`; навыки находятся в `.agents/skills`. Если папка открыта не как корень проекта, укажите её путь и попросите прочитать её `AGENTS.md`.

При необходимости подключите CapCut через установленный плагин Codex и завершите вход и согласие в интерфейсе. Проверка входа на сайт CapCut и доступность MCP — разные этапы. При проблемах попросите Codex использовать актуальные инструкции авторизации установленного плагина.

## Как пользоваться

Напишите задачу обычными словами и приложите файлы или укажите полные пути. Например:

```text
Работаем в CapCut Web. Из видео [путь] сделай вертикальный рилс
на 45 секунд об [идея]. Стиль — как в референсе [путь].
Сохрани облачный проект и подготовь MP4.
```

Для готового ролика:

```text
Добавь к [путь к видео] motion-графику: схемы и анимированные
надписи на ключевых фразах. Сохрани длительность, склейки,
голос и музыку. Референс стиля: [путь или описание].
```

Другие примеры: «добавь русские субтитры», «убери паузы и дубли», «продолжи по [путь к STATE.md]». При желании используйте подробный [шаблон нового рилса](ПРОМПТ_ДЛЯ_НОВОГО_ЧАТА.txt).

Результаты новых работ размещаются в `_монтаж/reel_NN`; эта папка исключена из Git. Ссылка на облачный проект и готовый MP4 — отдельные результаты: проверяйте оба, когда они нужны.

## Состав

| Навык | Назначение |
|---|---|
| `reel-director` | Выбор сценария, полный процесс для нового рилса и сохранение прогресса |
| `capcut-rough-cut` | Отбор фрагментов, удаление пауз/дублей и черновой монтаж |
| `capcut-finish` | Motion, фон, субтитры, звук и отдельные правки |

Маршрутизация находится в [.agents/skills/reel-director/references/task-routing.md](.agents/skills/reel-director/references/task-routing.md). В `.agents/skills/reel-director/scripts/reel.mjs` есть локальные команды `doctor`, `inspect`, `init`, `verify`. `init` требует отдельный видео-референс, а `verify` рассчитан на вертикальный H.264/AAC: для иных заданий агент проверяет реальные параметры подходящим способом.

## Ограничения и проверка

Плагин CapCut, экспорт, платные модели и доступные эффекты зависят от аккаунта и текущих возможностей сервиса. Если проект или экспорт недоступен, агент должен назвать конкретный незавершённый этап. MP4 с уже объединёнными слоями не позволяет автоматически редактировать каждую надпись и фон по отдельности; иногда требуется пересборка из исходников.

Локальные проверки на синтетических файлах, без реальных проектов и платных API:

```bash
node tests/check-kit.mjs
```

Набор является адаптацией рабочего процесса монтажа для Codex и CapCut. Права на сторонние шрифты, музыку, изображения и другие медиа проверяются отдельно; включённый здесь код не устанавливает лицензию на них.
